# 日本語の音声合成のモデル

デモサイトの日本語のクローン (Step 3) で、サーバが使う、学習済みのモデルです (`server/tts.py` が、起動時に読み込みます)。公開用の `site/` には含めません。
`manifest.json` が、ファイルの一覧、大きさ、sha256、版番号を持ち、読み込むときに、サーバが、つないだ内容の大きさと sha256 を確かめます (合わなければ、日本語は使えません)。
1 ファイルが 20 MiB 以下になるよう、大きなファイルを分割しています (`*.part0`, `*.part1`, ...。git で扱いやすくするため)。

| ファイル | 内容 |
|---|---|
| `ja_encoder.onnx` | 入力記号 -> エンコーダの出力と、デコーダの cross-attention の key / value |
| `ja_decoder_step.onnx` | デコーダの 1 ステップ分 (KV キャッシュの入出力、文の終わりの検出に使う注意 `align` を出力) |
| `ja_postnet_vocoder.onnx` | メルスペクトログラム -> postnet -> HiFi-GAN -> 波形 |

- **モデル:** Microsoft SpeechT5 (MIT) を、日本語の音素と韻律記号 (47 記号。`server/data/tts.json`) に対応させて追加学習したもの。20,000 ステップ。重みは fp16 で保存し、計算は fp32 で行います (ONNX Runtime、CPU)。
- **学習データ:** JVS コーパス (96 話者)、JSUT コーパス (basic5000)、LibriTTS の一部 (英語を忘れないため)
- **利用条件:** JVS と JSUT の音声の利用は、学術機関の研究、非営利の研究 (企業内を含む)、個人利用に限られ、再配布は認められていません。このモデルは、その条件に従い、非営利の研究・個人利用に限って使ってください。学習済みの重みの公開が、再配布に当たるかは、コーパスの規約からは判断できません。
- **版番号 (`manifest.json` の `version`):** モデルを差し替えるときは、増やしてください (以前、ブラウザに保存された古いデータを取り直すために使っていた番号です)。
- **サイトとの関係:** 以前は、ブラウザが、このモデルと、音素化の辞書を、取得して動かしていました。現在は、サーバだけが読み込み、利用者のブラウザには配信しません。
