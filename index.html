Voice Protection Demo
音声プライバシー研究

声を守るために、
話者の特徴だけを削る。

デモを始める
  • 音声はブラウザの外へ送信しません
  • x-vector + SpeechT5

3つのステップで試す

PC のブラウザを推奨します。処理はすべてお使いの端末で実行するため、端末の性能によって時間が変わります。

Step 1

声を録音する

好きな言葉で話してください。録音できる声はご本人のものに限ります。

0.0 秒

5〜8 秒ほどが目安です。無音の部分は自動で取り除き、最長 8 秒を使います。

録音した音声
Step 2

録音からマスクを最適化し、話者の特徴を選んだターゲット話者の方向へずらします。

Step 3

好きな文章でクローンする

入力した文章を、録音と敵対的音声それぞれの話者埋め込みで SpeechT5 に読み上げさせ、結果を比べます。

0 / 200

SpeechT5 は英語専用です。数字は英単語に展開して読み上げます。

初回のみ音声合成モデル（約 189 MiB）を Hugging Face から取得し、次回からはブラウザに保存した分を使います。取得するのはモデルだけで、音声や文章は送信しません。

使用しているモデルとライブラリ

  • 話者エンコーダ: SpeechBrain spkrec-xvect-voxceleb（Apache-2.0）
  • 音声合成: Microsoft SpeechT5 / HiFi-GAN（MIT）、ONNX 変換は Xenova/speecht5_tts
  • ターゲット話者の埋め込みと参照音声: LibriTTS（CC BY 4.0）。参照音声は発話を 16 kHz モノラルに変換し、音量を調整したもの
  • ONNX Runtime Web（MIT）、Inter（OFL-1.1）、Lucide（ISC）

プライバシー

録音した音声と入力した文章は、お使いのブラウザの中でのみ処理します。ページを閉じると録音は消えます。ブラウザに保存するのは音声合成モデルだけです。
